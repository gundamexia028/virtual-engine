# 医学依据索引

## 1. 目的与边界

本索引用于说明系统内严重过敏反应教学规则的公开医学依据，以及医学知识如何被转化为病例状态、动作节点、动态规则、评分与反馈。它不替代原始共识，不构成临床诊疗建议。

系统仅用于护理教学、培训与科研可行性验证。实际临床处置应由具备资质的医务人员依据患者情况、所在机构制度和最新指南作出判断。

## 2. 主要医学依据

中国康复医学会变态反应性疾病康复专业委员会，中华医学会变态反应学分会过敏原特异性诊断学组，中华预防医学会过敏病预防与控制专业委员会，等. 严重过敏反应诊断和临床管理专家共识[J]. 中华预防医学杂志, 2025, 59(6): 749-765. DOI: 10.3760/cma.j.cn112150-20250109-00024.

## 4. 原创性边界

不主张原创的内容：严重过敏反应的医学定义、诊断标准、药物剂量、治疗原则及公开指南知识。

团队自主完成的内容：

1. 将公开医学知识转化为可执行的护理教学目标与病例脚本；
2. 动态分支、时间推进、动作—后果和状态演化规则；
3. 临床与学院双模式及不同角色边界；
4. 过程评分、关键时间点记录、风险标签、即时反馈与复盘报告；
5. 情景注册、加载、流程策略、权限、数据导出及自动化测试的软件实现。

## 5. 维护要求

新增或修改医学规则时，应同时更新：情景JSON、必要的引擎实现、行为契约、黄金行为快照、自动化测试和本索引。未经医学审核，不得仅依据生成式人工智能输出修改剂量、适应证或急救顺序。
