# 五项流程收口补丁：1.3.9-audit.2

日期：2026-10-06。修改前版本：1.3.9-audit.1；来源部署提交：4a3e619b1287ecc16b5a9a9f80e82fea9502d39d。原部署源码归档 SHA256：95c483134bb1e838fd114c5d9b62025e460b5f794c9650342e8f07c0aca00c79。

本次在独立云副本修改，没有覆盖原包、操作另一个 simulation 仓库、提交 Git 或发布部署。此补丁仅闭合已确定的软件契约，不构成医学审核通过。

## 修改内容

1. C01：所有普通成功出口共享既有必做清单；临床漏 ABC/体位不能经 JSON 成功条件绕过。既有抢救转运、失败、超时和手动结束保留独立语义，手动结束不伪装为标准成功。
2. C02：临床继续输注同时设置 stopped_infusion=false、infusion_running=true。再次停药后可再次触发继续输注；正在输注时重复点击仍保留一次性防抖。继续暴露和停药后病程使用原数值与规则，没有新增医学参数。
3. C03：学院成功训练保持终态只读与成绩锁定；确认框取消按钮显示“返回查看”，并明确重新练习需重新开始。未完成且允许手动结束的其他场景仍显示“继续操作”。不宣称已恢复成功后的治疗。
4. C04：学院复评加入可重复观察名单，命令可继续记录复评并推进一时间步；首次有效时间与一次性得分不变。未实际给药或未满足复评前提仍不计有效复评。
5. C05：学院历史顺序违规纳入 process_safety_issues，标明后已补救或尚未有效补救，保留原原因及原始时间记录。已补齐的当前缺项清单与历史错误分别呈现；不恢复扣分。

## 不改变的边界

- 学院仍是既定角色内首轮配合，没有新增实际补液、重复肾上腺素或 CPR 权限
- 临床罚分独立记账、学院扣总分的既有区别保留；临床主分100仍可能伴随 penalties>0，两模式分数不可直接等价
- 未新增或更改剂量、阈值、病程速度、医学指南依据、数据库结构、Secrets、认证及权限默认拒绝策略
- 两份学院病例 JSON 保持字节不变；临床两 JSON 只补一个状态标志
- runtime ENGINE_REVISION 升为 audit.2，旧修订快照将按现有规则拒绝恢复，避免将旧冻结/矛盾状态直接带入新会话；部署前请完成正在进行的演练
